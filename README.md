# 🧮 Dart Scientific Calculator (CLI)

A clean, interactive, command-line Scientific Calculator written in **Dart**. It supports basic arithmetic operations as well as trigonometric functions, roots, powers, and natural logarithms.

---

## ✨ Features

- ➕ **Addition**
- ➖ **Subtraction**
- ✖️ **Multiplication**
- ➗ **Division** (with divide-by-zero protection)
- 📐 **Square Root**
- ⚡ **Power** ($x^y$)
- 📈 **Trigonometric Functions**: `sin`, `cos`, `tan` (angles in radians)
- 🪵 **Natural Logarithm**: `log(x)`
- 🛡️ **Robust Input Handling**: Will not crash on non-numeric or unexpected inputs.

---

## 🚀 How to Run

### Prerequisites
Make sure you have [Dart SDK](https://dart.dev/get-dart) installed on your system.

### Steps
1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/dart-scientific-calculator.git
   cd dart-scientific-calculator
   ```

2. **Run the program**:
   ```bash
   dart run bin/main.dart
   ```
